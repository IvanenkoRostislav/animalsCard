# 🐾Animals Card

Animals Card is an interactive animal-themed quiz game built with React and TypeScript.

The project is currently under active development.

## About the Project
Players interact with animal cards, identify animals, and answer questions about them to earn points.
The goal is to create an engaging and educational game that combines entertainment with interesting facts about wildlife.

## 🛠 Tech Stack
- React
- TypeScript
- Tailwind CSS
- Vite

##  Development Status
**Current stage:** MVP development
Features in progress:
- Interactive animal cards
- Animal identification
- Quiz questions
- Score tracking
- Game interface

## Future Plans
- Improve game logic and scoring
- Add more animals and questions
- Introduce additional game modes
- Refactor the codebase and improve component architecture

## Running Locally
```bash
npm install
npm run dev
```
